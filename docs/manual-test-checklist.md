# قائمة الاختبار اليدوي — قبل أي نشر

هاي بوابة القبول النهائية للـ MVP. `core-game` و`core-network` و
الـ ViewModels مغطّيين باختبارات وحدة (`./gradlew test`)، بس طبقة
Nearby Connections نفسها **ما بتنختبر إلا على أجهزة حقيقية** — سلوكها
بيختلف بين المصنّعين وما بينعكس صح على المحاكي.

**الأجهزة المطلوبة:** جهاز للمضيف + جهاز لكل لاعب (٥ أجهزة عالأقل حتى
تنجرب دورة الفريق كاملة)، أندرويد ٨.٠ أو أحدث، البلوتوث والواي فاي مفعّلين على الكل، وGoogle Play Services محدّث.

## التركيب

```bash
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk   # على كل جهاز
```

## الصلاحيات

- [ ] أول تشغيل بيعرض شاشة شرح الصلاحيات قبل أي إشي
- [ ] الموافقة على الصلاحيات بتفتح الشاشة الرئيسية مباشرة
- [ ] رفض الصلاحية بيعرض رسالة واضحة مع زر «فتح إعدادات التطبيق»
- [ ] منح الصلاحية من الإعدادات والرجوع للتطبيق بيكمّل بدون إعادة تشغيل
- [ ] تنجرب على أندرويد ١١ أو أقدم (صلاحية موقع) وعلى ١٢+ (صلاحيات بلوتوث)

## الاتصال

- [ ] المضيف يبدأ الاستضافة، وأجهزة اللاعبين تلاقي اللعبة وتتصل بنجاح
- [ ] كل لاعب يدخل اسمه ويظهر بعمود فريقه عند المضيف
- [ ] اللاعبين بينوزعوا بالتناوب على الفريقين وبيضل العدد متوازن
- [ ] أول لاعب بكل فريق معلّم «المنصة»
- [ ] زر «بدء اللعبة» ما بينفتح إلا لما يكون بكل فريق لاعب متصل

## شاشات اللاعبين

- [ ] كل الشاشات (مضيف ولاعبين) بالوضع الأفقي وما بتدور مع الجهاز
- [ ] ولا لاعب بيشوف نص السؤال ولا نصوص الأجوبة المخفية على جهازه
- [ ] لما يفتح الزر: شاشة اللاعب بتومض أبيض/أسود وبتضل تومض
- [ ] بمجرد ما يلمس: الشاشة بتصير زرقا عنده وبتبيّن «ضغط» عند المضيف
- [ ] حكم «صح» بيخلي شاشته خضرا، و«غلط» بيخليها حمرا
- [ ] الأحمر بيضل لحد ما يرجع دوره بعد ما يجاوبوا كل زمايله
- [ ] لاعب مش دوره: ضغطه ما بيعمل إشي والشاشة بتضل غامقة

## المواجهة

- [ ] بأول جولة: أول لاعب بكل فريق بس اللي شاشته بتومض
- [ ] باقي اللاعبين ما بيقدروا يضغطوا بالمواجهة
- [ ] أول ضغطة بتقفل الزر عالتاني فوراً (الفرق محسوس، مو متأخر)
- [ ] كشف الجواب رقم ١ بالمواجهة → اللوح بينتقل فوراً لهاد الفريق
- [ ] كشف جواب أقل → الدور بينتقل للاعب المنصة التاني، والأعلى بياخد اللوح
- [ ] غلط من الاتنين → الزر بيرجع يفتح لنفس السؤال
- [ ] بالجولة الجاية: لاعب المنصة بيتبدّل للي بعده بالقائمة

## اللعب والسرقة

- [ ] بعد المواجهة الدور بينتقل **للاعب اللي بعد** لاعب المنصة، مش لنفسه
- [ ] كل حكم (صح أو غلط) بينقل الدور للاعب اللي بعده بالترتيب
- [ ] العمود الجانبي عند المضيف بيبيّن مين دوره ولون كل لاعب
- [ ] المضيف يدوس على خانة الجواب → الخانة بتنقلب عند الكل
- [ ] نقاط الجولة (pot) بتزيد مع كل جواب، وما بتنضاف لأي فريق قبل
      نهاية الجولة
- [ ] «غلط» بمرحلة اللعب بيزيد X وبيبيّن X كبير عند المضيف
- [ ] ثلاث X بتنقل الفرصة للاعب المنصة عند الفريق التاني
- [ ] سرقة ناجحة بتاخد كل نقاط الجولة، والفاشلة بترجّعها للفريق الأول
- [ ] نهاية الجولة بتكشف كل الأجوبة الباقية عند المضيف
- [ ] مضاعف الجولة (×٢ و×٣) بينعكس على النقاط المضافة

## الجولة السريعة

- [ ] بعد آخر جولة، زر «الجولة السريعة» بينقل الكل لشاشة الجولة السريعة
- [ ] بيلعبها أول لاعبين من الفريق المتصدّر
- [ ] الوقت بينزل ثانية بثانية عند المضيف وعند اللاعبين بنفس اللحظة تقريباً
- [ ] انتهاء الوقت بيسجّل باقي الأسئلة «ما جاوب» وبينقل للاعب التاني (٢٥ ثانية)
- [ ] جواب مكرر من اللاعب التاني بيعطي تنبيه أحمر وبيعيد نفس السؤال
- [ ] «اكشف النتيجة» بيعرض جدول اللاعبين والمجموع عند الكل
- [ ] المجموع بينضاف لرصيد الفريق، و«فوز!» بتظهر إذا وصلوا ٢٠٠

## الانقطاع والرجوع

- [ ] فصل جهاز لاعب أثناء اللعب (طفّي الواي فاي) → بينعلّم «غير متصل» عند
      المضيف بدون ما يطيح التطبيق
- [ ] الدور بيتخطّى اللاعب المنقطع وما بيعلق عليه
- [ ] جهاز اللاعب المنقطع يعرض «انقطع الاتصال»
- [ ] رجوع اللاعب المنقطع → بيرجع لنفس فريقه ونفس مكانه بالترتيب
- [ ] قفل شاشة جهاز اللاعب وفتحها ما بيقطع الاتصال

## النهاية

- [ ] «إنهاء اللعبة» بيعرض شاشة النتيجة النهائية عند الأجهزة التلاتة
- [ ] الفائز محسوب صح، والتعادل بينعرض كتعادل
- [ ] زر الرجوع للشاشة الرئيسية بيشتغل عند المضيف

## التوافق

- [ ] تكرار الاختبار على شركتين مصنّعتين مختلفتين (مثلاً Samsung وXiaomi) —
      سلوك Nearby Connections بيختلف بينهم فعلياً
- [ ] الواجهة كلها RTL وما في نص مقصوص أو مقلوب على شاشة صغيرة

## تجربة على جهاز واحد (أسرع طريقة)

من الشاشة الرئيسية: **تجربة على هاد الجهاز**. بتفتح لعبة كاملة بنفس محرك
اللعبة، بدون شبكة ولا أجهزة تانية: لوح المضيف عالشمال، وأربع «أجهزة
لاعبين» عاليمين. بتضغط على مربّع اللاعب بدل ما يضغط هو على جهازه.

- [ ] بالمواجهة: بس لاعب المنصة من كل فريق مربّعه بيومض «اضغط!»
- [ ] الضغط على مربّع بيخليه أزرق، والمضيف بيقدر يحكم
- [ ] كشف الجواب رقم ١ بياخد اللوح، والدور بينتقل **للاعب اللي بعده**
- [ ] كل حكم بينقل الدور للاعب اللي بعده بالترتيب
- [ ] ٣ أخطاء بتفتح السرقة للاعب المنصة عند الفريق التاني
- [ ] نهاية الجولة بتكشف اللوح وبتضيف النقاط × المضاعف
- [ ] الجولة السريعة بتفتح بعد آخر جولة

هاي التجربة بتغطي القواعد كلها بس ما بتغطي الشبكة — للشبكة شوف القسم
اللي تحت أو جرّب على أجهزة حقيقية.

## اختبار على محاكيات (بدون ٣ تلفونات)

Nearby ما بيشتغل عالمحاكي — بيحتاج بلوتوث وواي فاي حقيقيين. لهيك في
**وضع الاختبار (شبكة)** بالإعدادات: بيستبدل Nearby بوصل TCP عادي.

1. افتح المحاكيات كلها بـ `-read-only` (لازم كلهم، حتى الأول):
   ```bash
   emulator -avd <AVD> -port 5554 -read-only
   emulator -avd <AVD> -port 5556 -read-only
   emulator -avd <AVD> -port 5558 -read-only
   ```
2. ركّب التطبيق على الكل: `adb -s emulator-5554 install -r app-release.apk`
3. اربط المنافذ — المضيف `forward` وكل لاعب `reverse`:
   ```bash
   adb -s emulator-5554 forward tcp:5599 tcp:5599
   adb -s emulator-5556 reverse tcp:5599 tcp:5599
   adb -s emulator-5558 reverse tcp:5599 tcp:5599
   ```
4. على **كل** جهاز: الإعدادات ← وضع الاختبار (شبكة) ← فعّله.
5. جهاز المضيف: استضافة لعبة ← بدء البث. باقي الأجهزة: انضمام كلاعب.

إذا ما ظهر ولا لاعب، تأكد إنه المضيف سامع:

```bash
adb -s emulator-5554 logcat -d -s FeudLan
```

لازم تشوف `listening on port 5599`. وإذا بدك تتأكد من ربط المنافذ نفسها،
جرّب توصل من الكمبيوتر:

```bash
python -c "import socket;socket.create_connection(('127.0.0.1',5599),3);print('ok')"
```

> نفس الوضع بيشتغل على تلفونات حقيقية على نفس شبكة الواي فاي: حط عنوان
> المضيف بدل 127.0.0.1 (لسا بدها حقل بالواجهة).
