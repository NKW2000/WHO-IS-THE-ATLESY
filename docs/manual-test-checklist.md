# قائمة الاختبار اليدوي — قبل أي نشر

هاي بوابة القبول النهائية للـ MVP. `core-game` و`core-network` و
الـ ViewModels مغطّيين باختبارات وحدة (`./gradlew test`)، بس طبقة
Nearby Connections نفسها **ما بتنختبر إلا على أجهزة حقيقية** — سلوكها
بيختلف بين المصنّعين وما بينعكس صح على المحاكي.

**الأجهزة المطلوبة:** ٣ أجهزة أندرويد حقيقية (مضيف + فريقين)، أندرويد ٨.٠
أو أحدث، البلوتوث والواي فاي مفعّلين على الكل، وGoogle Play Services محدّث.

## التركيب

```bash
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk   # على كل جهاز
```

## الصلاحيات

- [ ] أول تشغيل بيعرض شاشة شرح الصلاحيات قبل أي إشي
- [ ] الموافقة على الصلاحيات بتفتح الشاشة الرئيسية مباشرة
- [ ] رفض الصلاحية بيعرض رسالة واضحة مع زر «فتح إعدادات التطبيق»
- [ ] منح الصلاحية من الإعدادات والرجوع للتطبيق بيكمّل بدون إعادة تشغيل
- [ ] تنجرب على أندرويد ١١ أو أقدم (صلاحية موقع) وعلى ١٢+ (صلاحيات بلوتوث)

## الاتصال

- [ ] المضيف يبدأ الاستضافة، وجهازا الفريقين يلاقوا اللعبة ويتصلوا بنجاح
- [ ] كل فريق يدخل اسمه ويظهر الاسم عند المضيف بشاشة الإعداد
- [ ] عدّاد «الفرق المتصلة» يوصل ٢/٢ وزر «بدء اللعبة» ينفتح
- [ ] جهاز ثالث يحاول ينضم → ينرفض برسالة «اللعبة ممتلئة» بدون ما يطيح شي

## اللعب

- [ ] المضيف يبدأ اللعبة، السؤال الأول يظهر على الأجهزة التلاتة
- [ ] فريق واحد يبزّ، الزر يقفل فوراً عند الفريق التاني (الفرق محسوس وسريع،
      مو متأخر بشكل ملحوظ)
- [ ] جهاز الفريق اللي بزّ بيعرض «بزّيت!» والتاني بيعرض «الفريق التاني بزّ»
- [ ] المضيف يعلّم «صح» → النقاط تتحدث عند الأجهزة التلاتة فوراً والجواب ينكشف
- [ ] المضيف يعلّم «غلط» → الزر يرجع يفتح للفريقين بدون نقاط
- [ ] الانتقال للسؤال التالي يشتغل ويعرض نفس الحالة عند الكل
- [ ] النقاط الظاهرة عند الفرق مطابقة للنقاط عند المضيف بكل لحظة

## الانقطاع والرجوع

- [ ] فصل جهاز فريق أثناء اللعب (طفّي الواي فاي) → المضيف يعرض «غير متصل»
      لهاد الفريق بدون ما يطيح التطبيق
- [ ] جهاز الفريق المنقطع يعرض «انقطع الاتصال بالمضيف»
- [ ] إعادة تشغيل واي فاي الفريق المنقطع → يقدر يرجع يتصل ويرجع لنفس فريقه
      **ونقاطه محفوظة**
- [ ] قفل شاشة جهاز الفريق وفتحها ما بيقطع الاتصال

## النهاية

- [ ] اللعبة توصل لآخر سؤال وتعرض شاشة النتيجة النهائية عند الأجهزة التلاتة
- [ ] الفائز محسوب صح، والتعادل بينعرض كتعادل
- [ ] زر الرجوع للشاشة الرئيسية بيشتغل عند المضيف

## التوافق

- [ ] تكرار الاختبار على شركتين مصنّعتين مختلفتين (مثلاً Samsung وXiaomi) —
      سلوك Nearby Connections بيختلف بينهم فعلياً
- [ ] الواجهة كلها RTL وما في نص مقصوص أو مقلوب على شاشة صغيرة

> أي مشكلة بتطلع بهاي القائمة تتسجّل كـ issue قبل النشر.
