# تحدي العائلة (Family Feud style)

لعبة أسئلة جماعية للأندرويد على غرار Family Feud — مضيف واحد وفريقين
بيتصلوا محلياً عبر Nearby Connections، **بدون سيرفر وبدون إنترنت**.

## كيف بتشتغل

- **جهاز المضيف** بيعرض السؤال والأجوبة وبيحكم صح/غلط. هو مصدر الحقيقة
  الوحيد لحالة اللعبة.
- **جهاز كل فريق** زرّ (buzzer) فقط: بيبعت البزّة وبيعرض الحالة اللي
  بتوصله من المضيف. ما بيحسب ولا بيقرر إشي محلياً.
- أول فريق بيبزّ بيقفل الزر على التاني لحد ما المضيف يحكم.

## بنية المشروع

| الموديول | الشغلة | يعتمد على أندرويد؟ |
|---|---|---|
| `core-game` | محرك القواعد: الحالة، البزّ، النقاط، الانتقال بين الأسئلة | لأ — كوتلن نقي |
| `core-network` | بروتوكول الرسائل وغلاف Nearby Connections | إي |
| `data-questions` | بنك الأسئلة (٥٠ سؤال) وقارئه | لأ — كوتلن نقي |
| `app` | واجهات Compose وViewModels والتنقّل | إي |

`core-game` مقصود يضل بدون أي `import android.*` حتى يضل قابل لاختبار
وحدة كامل بدون جهاز ولا محاكي.

## البناء

بتحتاج JDK 17 وAndroid SDK (platform 34, build-tools 34.0.0). حط مسار
الـ SDK بملف `local.properties`:

```properties
sdk.dir=/path/to/Android/sdk
```

```bash
./gradlew test            # اختبارات الوحدة لكل الموديولات
./gradlew assembleDebug   # ينتج app/build/outputs/apk/debug/app-debug.apk
```

## التشغيل

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

ركّب التطبيق على ٣ أجهزة: واحد يختار «استضافة لعبة» والتنين التانيين
«انضمام كفريق». لازم البلوتوث والواي فاي يكونوا مفعّلين على الكل.

> **مهم:** Nearby Connections ما بينختبر بشكل موثوق على المحاكي. قبل أي
> نشر، نفّذ [قائمة الاختبار اليدوي](docs/manual-test-checklist.md) على
> أجهزة حقيقية.

## المتطلبات

- أندرويد ٨.٠ (API 26) أو أحدث
- Google Play Services محدّث
- صلاحيات البلوتوث/الواي فاي القريب (بيطلبها التطبيق أول تشغيل)
